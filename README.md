# EpubReader (Android EPUB 閱讀器)

這是一款專為 Android 打造的輕量、高度客製化且注重隱私的 EPUB 電子書閱讀器。提供流暢的閱讀體驗，並且完美支援中文的「直式排版」與「橫式排版」。

## ✨ 核心特色功能

- **完善的排版支援**：完美支援中文直式（右至左）與橫式（左至右）排版閱讀。
- **個性化閱讀設定**：
  - 支援匯入自訂字體（.ttf, .otf）。
  - 可自由調整字體大小。
  - 提供**日夜間模式**切換，保護您的眼睛。
  - 自訂翻頁方式（支援螢幕左右點擊、上下點擊，以及**音量鍵翻頁**）。
  - 沉浸式全螢幕閱讀體驗。
- **便利的閱讀工具**：
  - 自動記錄每本書的最後閱讀進度。
  - 支援章節目錄（ToC）快速跳轉。
  - 提供書籤功能，標記重要頁面。
- **流暢的效能與過渡動畫**：最佳化的章節載入與平滑的換頁過渡動畫。

## 🔒 隱私與資料安全聲明

**本軟體 100% 重視您的隱私。** 
所有的書籍檔案、閱讀進度、書籤與設定資料 **皆完全儲存於您的手機本機端**。
本應用程式**不會**將任何個人資料、閱讀紀錄或書籍內容上傳、回傳至任何伺服器或第三方機構。這是一款完全可以離線使用的單機應用程式，請安心使用。

## 🚀 如何安裝 (APK 下載)

## 下載安裝

1. 前往本專案的 [Releases](https://github.com/xing0501/EpubReader_Android/releases/tag/v1.0) 頁面。
2. 找到最新版本的發佈，點擊下載附帶的 `.apk` 檔案（例如：`EpubReader_1.0.apk`）。
3. 下載完成後，點擊該 APK 檔案進行安裝。
   > **注意**：如果您的手機未曾安裝過非 Google Play 商店的應用程式，系統可能會提示您「不允許安裝未知的應用程式」。請前往手機的**設定 > 安全性**（或應用程式權限），允許您的瀏覽器或檔案管理器「安裝未知的應用程式」。
4. 安裝完成後，即可在桌面找到 `EpubReader` 點擊開啟並匯入您的書籍開始閱讀！

## 🛠 開發與技術棧

- **語言**: Kotlin
- **UI 框架**: Jetpack Compose
- **架構**: MVVM (Model-View-ViewModel)
- **資料庫**: Room Database (儲存書籍資訊、書籤與字體設定)
- **電子書解析**: EPUBLib (自定義解析邏輯與 WebView 渲染)
